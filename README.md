# نظام الصفا والمروة — مشروع .NET MAUI لويندوز

مشروع Windows x64 بواجهة عربية وقاعدة بيانات SQLite محلية، مع إعداد بناء سحابي عبر GitHub Actions حتى يمكن رفع الملفات وتشغيل البناء من الهاتف.

## الوظائف الموجودة في هذه الحزمة
- شاشة تسجيل نقلة بتاريخها.
- رقم وحروف السيارة ورقم وحروف المقطورة.
- اسم العميل واسم القائم بالتكعيب.
- أبعاد الوش والمقطورة (الطول × العرض × الارتفاع) بالمتر.
- حقل الوضع الإضافي والملاحظات والخصم المخصص.
- حساب وعرض الحجم وفق المعادلة البرمجية الحالية.
- حفظ النقلات في SQLite محليًا، وعرض أحدث 50 نقلة.
- حذف منطقي يحتفظ بالسجل داخل قاعدة البيانات ولا يمسحه نهائيًا.
- إنشاء نسخة احتياطية من قاعدة البيانات داخل Documents\\SafaaAndMarwaBackups.
- توقيع الإعداد وعبارة الدعاء على الشاشة.

## طريقة بناء نسخة Windows من الهاتف عبر GitHub
1. أنشئ مستودعًا جديدًا على GitHub.
2. فك ضغط هذا الملف ZIP على هاتفك، ثم ارفع **محتويات المجلد** إلى جذر المستودع، وليس ملف ZIP نفسه.
3. افتح تبويب Actions في المستودع واسمح بتشغيل GitHub Actions إذا ظهر طلب.
4. اختر Build Windows EXE ثم Run workflow.
5. انتظر انتهاء المهمة بحالة Success.
6. افتح تشغيل المهمة، ثم نزّل Artifact باسم `SafaaMarwa-Windows-x64`.
7. انقل ZIP الناتج إلى جهاز Windows وفك ضغطه بالكامل، ثم شغّل `SafaaAndMarwaSystem.exe`.

## متطلبات التشغيل
- Windows 10 أو Windows 11 بنظام 64-bit.
- شغّل البرنامج من داخل المجلد بعد فك الضغط، ولا تنقل EXE وحده؛ ملفات النشر المرافقة ضرورية.

## مكان قاعدة البيانات
تُحفظ قاعدة البيانات في مجلد بيانات المستخدم المحلي تحت:
`%LOCALAPPDATA%\\SafaaAndMarwaSystem\\safaa_data.db3`

النسخة الاحتياطية في مجلد المستندات. احتفظ بنسخ احتياطية خارج الجهاز أيضًا. لا تفترض أن حذف البرنامج أو إعادة تثبيته سيحافظ على البيانات تلقائيًا.

## تنبيه مهم قبل الاستخدام الفعلي
هذه نسخة تشغيل أولية موسعة لإدارة سجلات التكعيب، وليست بعدُ نظام الحسابات الكامل أو كل الوظائف التي قد تكون موجودة في برنامجك الأصلي. معادلة الحجم الحالية هي مجموع حجمين متوازييْن مستطيليْن (الوش والمقطورة)، ثم خصم القيمة المدخلة مرة واحدة. لم يتم اعتماد هذه المعادلة كقاعدة محاسبية نهائية دون مطابقتها مع طريقة التكعيب الفعلية عندك. لا تعتمد عليها في الحسابات الرسمية قبل مراجعة القاعدة واختبار أمثلة حقيقية.

## حالة الاختبار
تم تجهيز ملفات المصدر وملف GitHub Actions. لم يتم تنفيذ بناء Windows فعلي في هذه البيئة، لذلك لا أصف الحزمة بأنها EXE مجرّب أو أؤكد نجاح التثبيت قبل ظهور نتيجة GitHub Actions على المستودع.
